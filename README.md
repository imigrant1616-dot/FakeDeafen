# 🎧 FakeDeafen - Vencord Plugin

A discreet and powerful **Fake Deafen & Fake Mute** plugin for [Vencord](https://vencord.dev). It makes you appear completely deafened and muted to everyone in voice channels while allowing you to hear everything and speak silently without any green speaking indicator.

---

## ✨ Features

- **🎧 Fake Deafen & Fake Mute**: Displays the muted microphone and deafened headphones icons next to your name in voice channels and direct calls.
- **🚫 100% Silent Mic (No Speaking Ring)**: Completely suppresses and hides the green speaking indicator / avatar ring everywhere on Discord.
- **⚡ Convenient Toggle**:
  - Quick toggle button in the bottom-left account bar.
  - Keyboard shortcut: **`Ctrl + Shift + Q`**.
- **🛡️ 100% Undetectable**: Operates entirely client-side without sending automated voice spam.

---

## 🚀 Installation

### Method 1: Userplugins (Recommended)
1. Clone or download this repository into your Vencord `userplugins` directory:
   ```bash
   cd Vencord/src/userplugins
   git clone https://github.com/imigrant1616-dot/FakeDeafen.git fakeDeafen
   ```
2. Build Vencord:
   ```bash
   pnpm build
   ```
3. Restart / reload Discord (**Ctrl + R**).
4. Go to **Settings -> Vencord -> Plugins** and enable **FakeDeafen**.

---

## 🛠️ Usage

1. Click the **FakeDeafen icon 🎧** in the bottom-left corner next to your mic/headphones (or press **`Ctrl + Shift + Q`**).
2. The button turns red/active, and your voice state shows you as deafened/muted to everyone in the channel.
3. You can still hear everyone and talk freely without the green speaking glow appearing on your avatar!
